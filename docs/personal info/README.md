# Personal info (upload guide)

Non-technical notes on what to keep in Supabase for job applications.

**Rule for these files:** describe categories and formats only. Never put real names, emails, phone numbers, addresses, dates of birth, SSN, salary numbers, or demographic answers here. Real values live in Supabase (`personal_info_and_docs`).

| File | Purpose |
|------|---------|
| [inventory.md](inventory.md) | Do not copy stored records into this repo |
| [career-materials.md](career-materials.md) | Resumes, letters, portfolio, proofs of skill |
| [application-answers.md](application-answers.md) | Form fields employers ask repeatedly |
| [preferences.md](preferences.md) | Targeting, compensation, availability |

Status labels used in these docs:

- **Present** — already in Supabase
- **Suggested** — not uploaded yet; useful for applications
- **Optional** — only when a role asks for it
