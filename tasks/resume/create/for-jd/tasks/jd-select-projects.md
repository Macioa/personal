# JD Select Projects

1. Review `<repo path>/temp/applications/[company-role]/temp/jd_requirements.md`, `skill_search_output.md` and `resume-view-projects.md`, same folder.
2. Select 3 projects that best fit job requirements. Prioritize explicit skill matches.
   - A skill in the same "Other" group as an explicit JD skill in `skill_search_output.md` counts as an explicit match. Order: explicit JD skills, then their stand-ins, then congruent skills.
3. For each: select 5 skills used that give best alignment and full coverage of requirements. Select only from that project's own `skills`. Do not add, rename or reword.
4. Output to `selected_projects.md`, same folder, JSON format. Keep all resume view data for the 3 projects verbatim; only `skills` (5) is reduced.
