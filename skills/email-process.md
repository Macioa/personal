# Email Process

Connect to my Gmail using Composio. Scan my temp/mail folder. For each md in the folder, perform the requested task (send the email, create the folder, etc...). If the md was processed successfully, remove the md from the folder. If the md process failed, add a failure report to the md including number of failures and suspected reasoning for failures. After completion, report the success percentage, total success/fails, and list the failed items with short answer styling.
